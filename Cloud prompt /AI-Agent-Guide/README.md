# AI Agent Master Guide Folder (`AI-Agent-Guide/`)

This folder contains the complete, copy-paste-ready **Enterprise Luxury E-Commerce Architecture & Prompt Blueprint** so you can instruct any AI Coding Agent (Arena Agent Mode, Claude, ChatGPT, Gemini, Cursor, Windsurf, etc.) to build or upgrade a store with the exact **Zariya Jaipur / Liksha Clothing / The Store of Bufani / Amazon-Flipkart** architecture.

## Files in This Folder
1. **`01-FULL-STACK-MASTER-PROMPT.md`** — The single all-in-one prompt you can give to any AI agent at the start of a project (`Read this file and follow step by step`).
2. **`02-UI-UX-POPUP-MOBILE-STANDARDS.md`** — Mobile-first (`90%+` mobile users) layout rules, Zero-Emoji policy, 1-second animated Add-to-Bag popup that collapses into the bottom bar, mandatory `×` (Cross) close/remove buttons on all popups & Compare, 6-image studio galleries, and `XS [34]`–`3XL [46]` dynamic size pricing + live garment measurements.
3. **`03-ACCOUNT-OTP-GST-SECURITY-DB.md`** — 4-way verified Email & OTP Authentication (Password Login, Passwordless Email OTP Login, OTP Registration, Forgot Password OTP Reset), 4-tab Amazon/Flipkart Account Hub (Orders, Cloud Wishlist, Saved Address Book, Security), CGST Rule 46(b) Invoice, Store Owner PIN Serviceability Engine, and PostgreSQL 17 / Supabase schema.
